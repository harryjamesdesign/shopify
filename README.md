My best previous work history

One of my previous work is https://doyoueven.com.
It involved improving the website of an Australian-founded fitness apparel and activewear e-commerce brand. This Shopify store offers a wide range of gym-ready clothing and accessories, including seamless leggings, crop tops, shorts, T-shirts, jackets, compression wear, and gear like socks, towels, and gym sacks. The store caters to both men and women with specialized collections such as Hyperflex and Scrunch Seam.

When I joined the project, the landing page lacked product information, which made it difficult for customers to browse and engage with the offerings without navigating to individual product detail pages (PDPs). I suggested and implemented a change to display featured product information directly on the landing page. This improved the user experience significantly by helping customers discover products faster and engage more efficiently.

Another key improvement was related to the product variant options. Previously, variant selection was implemented through an image slider, which was not intuitive and didn’t support standard clothing sizes like XL or L. I refactored this section using Shopify's theme customization capabilities to include clearly labeled size buttons, ensuring better accessibility and usability.

I also optimized the add-to-cart and checkout flow. Instead of requiring users to visit the PDP to add an item, I implemented a feature where clicking on a size button instantly adds the product to the cart. This streamlined the shopping experience and reduced friction. Additionally, I made the checkout button more visually prominent on the cart drawer, improving visibility and encouraging faster conversions.

From a technical perspective, I utilized Shopify’s Liquid templating language, metafields for storing custom product data, and AJAX API for seamless cart interactions. These changes not only improved the frontend experience but also aligned with the client’s goal of increasing conversion rates and enhancing user satisfaction.

Overall, this project was a strong example of how thoughtful Shopify theme development can improve both usability and business outcomes.
